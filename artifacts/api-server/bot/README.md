# Xevora System

هذا هو الأساس modular لبوت Discord، ومصمم لإضافة أنظمة مستقبلية دون خلطها
مع نقطة تشغيل البوت.

## التشغيل

1. أضف `DISCORD_TOKEN` إلى أسرار بيئة التشغيل لدى منصة الاستضافة.
2. شغّل الخدمة باستخدام:

   ```bash
   pnpm --filter @workspace/api-server run dev
   ```

3. بعد اتصال البوت بنجاح، يظهر أمر `/ping` في Discord ويرد بالعربية.

لا تضع التوكن في ملفات المصدر أو ملفات السجل أو مستودع Git.

## البنية

- `index.js` — إنشاء عميل Discord، تسجيل الأوامر، معالجة الأحداث، والإيقاف.
- `commands/index.js` — نقطة تجميع الأوامر وموزعها.
- `commands/ping.js` — أمر `/ping` الأول.
